# Quarkus - Supersonic Subatomic Java

* Quarkus
  * == framework for writing Java applications
    * **Container First**
      * == optimal for running | containers
      * minimal footprint == [LESS required resources](https://github.com/dancer1325/quarkusio.github.io/blob/main/_includes/performance.md)
      * TODO: how to check
    * **Cloud Native**:
      * embraces [12 factor architecture](https://12factor.net)
        * _Example:_ Kubernetes
        * TODO: how to check
    * **imperative (== non-blocking) + reactive** styles of development
    * **Standards-based**:
    Based on the standards and frameworks you love and use (RESTEasy and JAX-RS, Hibernate ORM and JPA, Netty, Eclipse Vert.x, Eclipse MicroProfile, Apache Camel...).
    * **Microservice First**:
    Brings lightning fast startup time and code turnaround to Java apps.
    * **Developer Joy**:
    Development centric experience without compromise to bring your amazing apps to life in no time.
